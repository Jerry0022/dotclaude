Analyse

  • Die Stufe, auf der du bist, ist lang; die anderen sind kurz. Titel = Name im Stepper, keine Nummern.
  • Kurz = ein Satz + Mini-Grafik oder Kennzahl; ohne Zahl Formatierter Text.
  • Lang scrollt nie — Belege öffnen als Popup.
  • Akkordeon: eine Stufe auf, die andere zu.
  • Das Briefing klappt nach dem Start zu und bleibt aufklappbar.
  • Themenfeld kurz = sein Ergebnis, nie der Fortschritt.
  • Nach dem Entscheiden zeigt die Entscheidung die Folge deiner Wahl.
  • Übergänge 300–450 ms je Schritt, ease-out; bei „Bewegung reduzieren“ sofort.

Entscheidung

  • Höchstens 3 Themenfelder mit je ≤ 7 Entscheidungen.
  • Das einzige Label ist die Empfehlung: Badge an der Option, das Warum im Tooltip.
  • Jede Entscheidung hat eine Vorauswahl — die Empfehlung.
  • „Gilt für“ ist leiser Text über der Frage; keine Tragweite, Status nur im Stepper.
  • Die Antworten beantworten genau diese Frage.
  • Ein klares Weiter unten rechts.
  • Kein „alle wie empfohlen“ — du klickst jede durch.

Review & Runde

  • Unberührt = nie geöffnet oder kürzer als 3 s; länger offen = Vorauswahl bestätigt.
  • Reihenfolge: Abweichungen, Issues, Unberührtes; Sprung zum ersten Unberührten.
  • „Was deine Auswahl bewirkt“ immer mit Grafik — gerechnet, wo es geht.
  • Absenden nur im ☰-Menü, kein zweiter Knopf.
  • 💬 ist auf jedem Screen da.
  • Nächste Runde: zurück zum Briefing; drei kurze Fragen, die warten können.
