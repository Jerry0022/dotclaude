## What the user said (German, verbatim gist)
Analysed the last 5 devops concepts and noticed:
a) in the overview the floating card (eyebrow "Holo-Deck", motto, 3 traits, ★) should ALWAYS be bottom-left.
b) the overview panel background is still not fully the variant's design.
c) when variants differ only by animation or sub-elements, the overview shows the same design 3× —
   instead show the non-design difference (the differing element, possibly animated).
d) unclear whether it is 3 completely different directions on every level vs 3 topics handled one
   after another vs one variant differing only in a sub-variant → make it understandable, and prevent
   a round that is 3× the same variant just because one or a few sub-pages differ.
e) with many sub-pages, clicking the dropdown/active chip should open the next sub-page of the same
   variant (rotation).
f) sometimes you want to concept A, then B, then C step by step — maybe auto-detected; then the main
   action is "next step" rather than "next round"/"implement now" (both must still exist: refine
   current step, or implement now and continue in parallel, or implement after).
g) (follow-up) variants need a number 1 2 3 in front — like the hotkeys, and so one can refer to them —
   in the quick navigation AND in the FAB (☰) menu.
