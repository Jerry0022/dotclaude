## Round 3 = design, `data-design-set="alternatives"`, 3 designs = three INTEGRATION places
All three keep Landkarte's structure model (Etappen = columns, variants = rows, detail
variants = dots in a cell) and the user's fixed points:
- quick nav starts with an overview link (icon, collapsed to the icon until hover), then
  "1 · Name" chips;
- Etappen as a VERTICAL named stepper (fixed width, e.g. 220px, label max ~24 chars, ellipsis
  never needed because Claude keeps to it — show the rule in an annotation);
- bottom submit row: in an Etappen concept "Nächste Etappe ›" replaces "Jetzt umsetzen"
  (no partial implement via UI); without Etappen everything stays exactly as today;
- no extra floating panel anywhere.
Designs:
- d1 "Im ☰-Menü" — stage completely clean; the ☰ panel holds: vertical Etappen stepper with
  names, the map grid as the panel's header, history (rounds) and table of contents.
- d2 "In der Schnellnavigation" — the map collapses into the quick-nav pill as a compact grid
  segment left of the variant chips (overview link → grid → chips); hovering expands it
  downward attached to the pill (part of the pill, not a separate panel); vertical stepper
  appears in the ☰ menu.
- d3 "Glyphe" (the counter-variant the user asked to keep) — the lit Etappen glyph from round 2
  s4 as the single structure indicator, sitting in the overview card / design header; it
  animates subtly on Etappe change; details in the ☰ menu.
Directions ("Richtungen") display must improve in every design: make it obvious that the
variants differ on EVERY level (e.g. per-variant colour band through all pages, page dots
showing "all pages differ").
Screens per design (same labels, genuinely different content): s1 "Richtungen", s2 "Etappen im
Menü/Stepper", s3 "Detail-Varianten", s4 "Absenden in Etappe", s5 "Ohne Etappen" (identical to
today's look is fine ONLY here; keep it minimal so P34 does not trip — differing chrome
placement is enough).
Each design: motto, 3 traits, icon, no data-design-overlay. ≤ 3 annotations per screen, ids
`r3-`. Intro: one clause on what round 2 decided (Landkarte, into the FAB menu, vertical named
stepper), then this round's question: where does the structure live?
Build with `node plugins/devops/scripts/concept-build.js build docs/concepts/20261028-1650-varianten-struktur`
(round 2 is baked). Gate must pass without V7/V8/P34. No browser, no bridge.
