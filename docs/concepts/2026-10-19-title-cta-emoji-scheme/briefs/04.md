## Apply
- Ready stays **📦**, in both the title and the CTA. The whole "code done locally" family uses 📦: ready `👉 📦 Ready`, ready-local `✅ 📦 Committed`, ready-files `👉 📦 Files`, and a generic abort `<abort> 📦 Aborted`. Drop 📝. ## Questions
- **Q-D abort status icon — boxed and red.** Be honest in the copy: Unicode has no red boxed ✖ emoji. ✅ is a green box, ⏸️ and ⏹️ are blue/grey boxes, ❎ is a green box. Options (bi-state cards with comment, ids):
  - `qd-stop` ⏹️ "Stop button", the same box family as ⏸️; its colour comes from the platform (Windows: grey/blue), so it is not red.
  - `qd-redsquare` 🟥, a red box with no symbol. Clearly red and boxed. **Recommended**: next to ✅ ⏸️ it reads as a red status light.
  - `qd-sos` 🆘, a red box with text; too alarming.
  - `qd-cross` ❌, red but without a box (the current choice).
  Show a mini sidebar under each option with the four statuses stacked, so the style comparison is visible: `✅ 🚀 Released Alpha – X`, `⏸️ 🔋 Limit reset – X`, `<option> 🚀 Ship – X`, `👉 📦 Ready – X`.
- **Q-E fallback activity icon.** Explain it in one plain sentence: the card used when Claude changed something OUTSIDE the repo with no code diff (a setting, a deploy, a database operation, a deletion). Options with keyword:
  - `qe-knobs` 🎛️ "Ops" (control panel, so "turned a knob somewhere"). **Recommended.**
  - `qe-cabinet` 🗄️ "System"
  - `qe-pc` 🖥️ "System"

  Each option gets its example title (`✅ <icon> <Word> – DB-Cleanup`).
