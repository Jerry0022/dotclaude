## The proposed scheme (author it as the centerpiece)
Rule: **bare ⏳ only while Claude generically works.** Every other state has two icons: STATUS + ACTIVITY, then one word, then " – " and the title.

STATUS icon (first), proposed set:
- ⏳ Claude is working on a named process (Shipping, Testing, Concept iterating/implementing, background agents)
- 👉 your move (a decision, test, approval or answer is needed)
- ✅ done, nothing open
- ❎ aborted (the "same-looking" cancel icon next to ✅; green square family)
- ⏸️ paused

ACTIVITY icon (second) = what the state is about:
🚀 Ship · 🎊 Release/Promote · 🧪 Test · ▶️ Start/Run · 🧭 Concept · 📥 Batch · 📋 Analysis · 🔧 Ops (outside repo) · 🛠️ Build (code ready, replaces 📦; see decision Q4) · ❓ Question · ⚠️ Warning (red tests / unverified) · 🤖 Agents (background work) · ⛔ Blocked.
Paused uses the pause reason as its activity icon: 🔄 Restart · 💻 Reboot · 🔋 Limit reset · ✋ by user.

Example sidebar per card state. Render it as one table: state | card variant/flag | title example | CTA line example (de). Use the round-1 `.d1-r1-sidebar` / table style; namespace all CSS with the `.d2-` prefix (gate P32: no bare classes).
