## Apply these (show in a "Übernommen aus Runde 2" block)
- "Your move" status = 👉.
- Abort status = **❌ (red)** instead of ❎. It belongs to the same "mark" family as ✅ but is clearly red. Show this as the new default, plus a small confirm card (Q-A below).
- F5, a turn that ends without a card: `👉 ⚡ Interrupted – X`. The Stop hook rewrites a bare-⏳ title. Batch, concept-waiting and shipping titles stay untouched.
- **Status rule for 👉 vs ✅ (from Q5):** the status is 👉 whenever the card carries a MANDATORY next step for the user: an open point, a required userTest, a requirement with waitsOn "user", a question, red tests, blocked. When the remaining steps are only optional (for example a promote offer after an alpha release, or "noch etwas?"), the status is ✅. The rule holds for every variant and is decided by card content, not variant name. The test matrix must assert it per flag.
- **Title = CTA:** the CTA heading of the card starts with exactly the same two icons and the same keyword as the title, so the card and the sidebar always read alike (Q4 note).
- Remove 📦 and 🛠️ entirely (Q4 all discarded, and the user finds 🛠️/🔧 unclear). New mapping:
  - ready (code done, "Ship?") → `👉 🚀 Ready – X`. The activity is the ship that is due; one icon covers the whole ship lifecycle: `⏳ 🚀 Shipping`, `👉 🚀 Ready`, `✅ 🚀 Released Alpha`.
  - ready-local (no remote, committed locally, nothing to ship) → `✅ 📝 Committed – X`.
  - ready-files (only files changed, commit?) → `👉 📝 Files – X`.
  - generic aborted → `❌ 📝 Aborted – X`. Named aborted keeps its activity, e.g. `❌ 🚀 Ship – X`.
  - fallback (work done OUTSIDE the repo with no repo diff: settings change, deploy, DB operation, deletion) → explain this plainly in the copy and ask for the icon (Q-C).
  - card component line (used 📦 before) → 🧩.
- 🔧 is gone from the activity set unless the user picks it in Q-C.
